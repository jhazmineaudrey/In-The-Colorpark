# In-The-Color-Park
A simple website about guessing the color based on the given hexcode that allows someone to somewhat understand/learn hexcodes, solely developed by Jazz. Inspired by Branko Stancevic's website made in CodePen (link is [here](https://codepen.io/landb/pen/bxVGVp)!)

This site was made for me to learn some more JavaScript logic, and get more used to the usage of Tailwind! Also mainly because I've been wanting to make a website game rather than a game in Godot, and I think this is a pretty cool simple game to get started on :]

## Features
**I. Difficulty Picker**
- Allows you to pick between the Easy, Medium, and Hard difficulties.

**II. Core Gameplay Mechanic**
- Includes randomization mechanic for both the choices and the hexcode you're supposed to guess. The amount of choices change depending on the difficulty you have selected. A streak counter is also included which allows you to see how many questions you got correct.

**III. Simple Data Storage**
- The website is able to remember your highest streak count (only in local storage at the moment - will be implemented once I learn backend!)

**IV. Responsive Design**
- This game/website is runnable and playable on almost all devices.

## How to Run
1. Go to [this](https://jhazmineaudrey.github.io/In-The-Colorpark) link, no need to install anything on your device.
2. Select a given Difficulty.
3. Guess the given hexcode's color from the given options (varies for each difficulty).
4. Feel free to check the information button to see how hexcodes work in order to better guess.

**If you would like to use the source code:**

1. Clone the repository.
2. Run the following command in your terminal in order to download the project's needed packages: `npm install` or `npm i`
3. Utilize `npm run build-css` to see live Tailwind CSS changes.
